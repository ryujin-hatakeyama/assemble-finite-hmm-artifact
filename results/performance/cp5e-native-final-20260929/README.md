# Archived native performance evidence: `cp5e-native-final-20260929`

This directory contains the measurements behind the performance figures
reported for the Grid3 and Grid4 models. The measurements were taken once, on
2026-09-29, and are archived here. They are not regenerated by the artifact
checks. `make verify-archived-performance` checks the archive and recomputes
every derived file from the raw timing rows and RSS logs, without modifying
this directory.

## Contents

| Path | Origin |
|---|---|
| `raw/all.csv` | All timed calls (19,200 rows), archived unchanged. |
| `runs/*/rss/*.log` | `/usr/bin/time -l` output for the compile-only processes (320 logs), archived unchanged. |
| `runs/*/metadata/conditions.txt` | Per-setting run parameters, archived unchanged. |
| `summary/metrics.csv`, `summary/process_runtime.csv` | Output of `bench/summarize_kernel_evaluation.py`; byte-identical to the archived files. |
| `analysis/pairwise_runtime.csv`, `analysis/condition_comparison.csv` | Output of `bench/analyze_kernel_evaluation.py`; byte-identical to the archived files. |
| `analysis/report.md` | Output of the current `bench/analyze_kernel_evaluation.py`; see "Changes from the archived files". |
| `metadata/conditions.txt` | Run-level parameters and environment; private fields normalized. |
| `metadata/git_status.txt` | `git status --short` of the source tree at run time, archived unchanged. |
| `SHA256SUMS` | Checksums of every other file in this directory. |

Some archived files are not included here. The per-process CSV and stderr files
under `runs/*/raw/` are omitted; `raw/all.csv` is their concatenation, with a
`process_run` column added. Also omitted are the stdout files of the
compile-only processes (`runs/*/rss/*.csv`), which no analysis reads, and the
figures, which `bench/plot_kernel_evaluation.py` regenerates from this
directory.

- **Observation sequence.** `observation[0] = (1,1)` and
  `observation[t] = (21,21)` for `1 <= t < T`. The source is the
  `observations` function in `bench/bench_kernel_evaluation.ml`.
- **Order balancing.** Process `r` uses order `(r-1) mod 4` from this list:

- **Timed region.** Each timed call is preceded by `Gc.full_major ()`. Time is
  measured as wall-clock time with `Unix.gettimeofday`.
- **BER MetaOCaml version.** The opam switch `5.3.0+BER` named in
  `metadata/conditions.txt` provides package `ocaml-variants.5.3.0+BER`. Its
  opam description is "BER-N153 MetaOCaml", with source archive
  `BER-N153.tar.gz`. The switch state was last modified on 2026-06-05, before
  the run. The archive does not record the BER release name itself.

## Timing boundaries

- **Kernel reference.** Each timed call runs ordinary inference, which builds
  the emission columns from the numeric emission kernel inside that call.
  Instantiating the numeric transition and emission kernels happens before
  timing.
- **Handwritten-Packed, staged Packed and staged Embedded.** These receive
  emission columns prepared before the timed call. For the staged
  implementations, specialization is also outside the timed call.
- Ratios against the Kernel reference are therefore end-to-end comparisons of
  implementations with different preparation boundaries. They do not isolate
  the effect of staging or of transition lowering.

## Statistics

- The runtime of a cell is the median, over its 8 processes, of each process's
  median over its 30 timed calls.
- A paired ratio such as Kernel/Packed is computed per process index; the
  table reports the median of the 8 per-process ratios.
- The cross-condition values in `analysis/report.md` are medians over the 20
  (model, query, transition setting) conditions.
- Specialization cost is the sum of three median phase times: lowering
  preparation, code construction, and running the generated code.
- Residual source size is the length of the generated code as printed by
  `Codelib.print_code`.
- Compile-only peak RSS is the "maximum resident set size" that
  `/usr/bin/time -l` reports for a separate process. That process builds the
  model and specializes it, then exits without timed inference.

## Source differences since the measured commit

The current artifact source differs from commit `a5520894` in the following
ways that affect code paths used by the benchmark:

- Viterbi backpointer arrays are initialized to `0` instead of `-1`.
- `Model_kernel.make` validates kernel rows when a kernel is constructed.
- `Model_kernel.instantiate` no longer rejects a statically positive edge
  whose weight evaluates to zero.

The remaining differences are comments and build scripts. The archived
measurements were not repeated after these changes.
